# Portal personal

Portal estático para GitHub Pages. Presenta tres casos de estudio: clasificación de datos con recomendación GenAI, gobierno de acceso con RBAC + ABAC y automatización en Databricks. No requiere instalación, base de datos ni servicios de pago.

## Publicación gratuita

1. Crea el repositorio público `DanielEnrique368.github.io` en la cuenta `DanielEnrique368`.
2. Sube el contenido de esta carpeta a la rama `main` del repositorio.
3. En GitHub abre **Settings > Pages** y selecciona **Deploy from a branch**; elige `main` y la carpeta `/ (root)`.
4. La página se verá en `https://danielenrique368.github.io`.

Para agregar otro caso de estudio, duplica un bloque `<article class="case">` dentro de `index.html` y cambia su título, descripción y capacidades.
